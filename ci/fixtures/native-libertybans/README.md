Each installed-native receipt verifies seven real public-API cases: no ban, active IP ban, exact UUID ban, foreign scope, expired, mute and revoked. The UUID probe is explicitly a synthetic contract input with verified-provenance metadata, not real Mojang/Xbox authentication or an actual forwarded player. Applicability alone missed its never-recorded UUID/address pair; native official API documents that boundary. The production reader now checks exact current victims first without manufacturing native history.

Each installed-native backend verifies six actual guard decisions: clear lookup joins; clear still permits normal VPN rejection; native ban rejects before any extra provider call; guard OBSERVE evaluates VPN and records the native ban while LibertyBans still independently rejects; after native removal a real client joins again; cancelling the guard runtime with CLOSED configured temporarily rejects before work. Two actual backend joins per fixture. Native final denial text is preserved even where LibertyBans changes the guard's platform message. SDK absence receipts verify actual addon loading and CLOSED refusal without provider work, OPEN still doing ordinary VPN detection, OPEN unknown reported as UNKNOWN_ALLOWED with actual join, and disabled selection returning to ordinary policy, and a cancelled guard runtime still honoring CLOSED. Absence fixtures compile without the native SDK.

The root operational driver is `tools/release_native_ban_backend_test.py`. Build via `./gradlew check shadowJar :adapters:libertybans:jar`; verify both archives and regression guards. On the explicitly approved runtimes, compile the selected `.java` fixture against the guard, addon, platform API and (only for installed-native fixture) the exact SDK JAR; package only `fixture/*.class`, matching descriptor and AGPL notice. Isolate native data/HSQL; disable bStats, use OFFLINE synthetic identity resolution, operator-select the bounded provider/observer/admission IDs, reload after addon/native startup, run the console `fixture-ban` commands shown in the fixture source and logins, then stop the owned runtime. Root driver records matching hashes, decisions, final outcomes and shutdown. Do not autoaccept an EULA on a new host or infer wider authorization from this fixture.

This earlier package covers backends. Subsequent actual [Velocity/Bungee qualification](../native-libertybans-proxies/README.md) covers the selected proxy builds with installed/absent native SDKs and documents their different native refusal ordering. Also unqualified: legacy Spigot/other versions/forks, genuinely authenticated accounts, real native historical-alt association scenarios and concurrent native configuration/ban changes as an atomic database admission transaction. The API contract tests cover bounded callbacks, late completion, removal/replacement and concurrent selected answers; those are synthetic, not native SQL saturation claims. No blanket integration/whole-matrix/challenge/differentiator completion is implied.
