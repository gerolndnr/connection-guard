# Owned native Cloud lifecycle fixture

This fixture qualifies the supplied integrated development archive on pinned Paper 1.21.11 build 132, Folia 1.21.11 build 14 or BungeeCord build 2100. It uses the existing local operations runtime/helpers, records their hashes, and accepts only artifacts under this checkout. Backend starts require the conscious EULA approval already recorded in the operations root; it does not add automatic EULA acceptance to Gradle or CI.

Run one platform at a time with `native_driver.py --operations-root /absolute/operations-root --artifact /absolute/checkout/build/libs/connection-guard-0.5.0-SNAPSHOT-all.jar --sha256 SHA256 --platform paper --fixture unique-fixture-name`, then Folia and Bungee with fresh names. Existing fixtures are never reused. Existing pinned runtimes and compile libraries must be provisioned. All HTTP, Minecraft listeners, unused proxy backend addresses and synthetic players stay on loopback. At most 768 MiB backend heap or 256 MiB proxy heap; final cleanup stops clients, server and local HTTP responder. No real Cloud session, provider subscription, account authentication or production installation is used.

The actual native reload applies a valid enforce draft, rejects a complete invalid draft while retaining the previous settings/overlay/custom language, resets to the local observe config, and honors the persisted Cloud-off command through reload. Actual synthetic native logins prove allow/refuse behavior. A deliberately hanging 15-second Cloud response must permit native reload and login refusal independently; plugin shutdown must cancel it and exit cleanly. Recorded single-login duration is a fixture deadline check, not a p95 benchmark or market comparison.

A local claimed API responder supplies the agreed protocol; this is native platform qualification, not a substitute for the separate actual Cloud API/dashboard/browser end-to-end test. Results bind the exact plugin, runtime, fixture addon, source and local helper hashes. None of these tests proves real operator onboarding or detection accuracy.
